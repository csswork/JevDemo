# 街景中的新天空审阅

打开 http://127.0.0.1:5678/sky-preview/ 。服务使用 `npm exec vite -- --config design/sky-preview/vite.config.mjs`。

此页复用 `src/vrm/scenes/street.ts` 的真实场景、资源和更新逻辑，没有复制一套会脱节的街景，也没有替换主应用的背景注册。旧天空/卷云只在此实例中隐藏。新天空单独画在街景之前，建筑正常遮挡云和星点。

新增海洋组件位于 `design/ocean-preview/oceanRenderer.ts`，在此页默认使用；海洋控制中可关闭新海洋来对比原版。复用原海岸的距离图和防波堤位置，默认双层 FFT 波场，128²/256² 可切换，也保留上一版解析波浪。新的波浪、材质、镜像反射与生命周期由独立组件管理。天空云形与其参数范围保持此前版本。

时间系统驱动街景原有主光、补光、半球光、雾、海面、路灯和店内灯。新日月采用街景的方位映射，使可见太阳与投影方向一致。海面反射层使用新天空的几何版本；材质环境光由新天空 PMREM 生成，时间/云量/月相改变时最多每秒重烘一次。风不会每帧触发重烘，因此材质 IBL 不会实时追随每一处云影；本页未实现体积云投向地面的动态阴影。

沿街/海景/全景三个视角，OrbitControls 支持左键旋转、右键平移、滚轮缩放；展开天空控制可调整时间、云量、风和质量。显示街景复选框可对比纯天空。没有角色、语音或主应用服务；资源保持本地加载。

## 双层云

积云云量与卷云云量分别调整，0% 完全关闭对应层。共用一个风场，控制时间或另一类云不会重置现有云量。卷云为高层稀薄丝缕，用较宽的弯曲云带包络、拉长的纤维噪声和尾部衰减形成断续羽状结构；下层积云在它前面合成，建筑又遮挡全部天空。卷云同时加入海面反射和材质环境烘焙；调整卷云量也会触发节流后的 PMREM 更新。

外观参考 WMO 国际云图的 [Cirrus fibratus / uncinus](https://cloudatlas.wmo.int/en/ch-1.html) 和公开卷云摄影，仅作形态参考，未下载或复制摄影贴图。新增层复用 R8 噪声缓存，不增加射线步进或新的渲染目标；归零后主画面、反射和环境场景都隐藏该层。滑杆表示云量强弱，不是屏幕云像素占比或气象观测值。

已实际检查只有卷云、只有积云、双层共存和双层归零。`cloud-layers.png` 为双层街景实际截图，`cirrus-only.png` 为只有卷云的截图。

卷云丝状修订：去掉二维高频扭曲，所有纤维保持同一主方向，只保留沿长度方向的缓慢、低幅剪切。纵横噪声尺度比约 1:20，沿长度方向缓慢衰减形成断续丝缕；不透明度系数从 0.60 降到 0.27。`cirrus-filaments.png` 为此次更淡、更规则的实际截图。

已检查资源就绪、旧天空移除、沿街白天、海景日落、夜晚路灯与星空，以及 WebGL 错误日志。独立天空基准不能代表这页完整街景的帧率。

天空渲染器已移入 `src/vrm/sky/skyRenderer.ts`，预览和正式街景共享它；正式控制位于调试面板“天空与时间”。本预览仍独立比较 FFT 海洋，正式街景海洋保持既有实现。
