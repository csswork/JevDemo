# 街景中的新天空审阅

打开 http://127.0.0.1:5678/sky-preview/ 。服务使用 `npm exec vite -- --config design/sky-preview/vite.config.mjs`。

此页复用 `src/vrm/scenes/street.ts` 的真实场景、资源和更新逻辑，没有复制一套会脱节的街景，也没有替换主应用的背景注册。旧天空/卷云只在此实例中隐藏。新天空单独画在街景之前，建筑正常遮挡云和星点。

时间系统驱动街景原有主光、补光、半球光、雾、海面、路灯和店内灯。新日月采用街景的方位映射，使可见太阳与投影方向一致。海面反射层使用新天空的几何版本；材质环境光由新天空 PMREM 生成，时间/云量/月相改变时最多每秒重烘一次。风不会每帧触发重烘，因此材质 IBL 不会实时追随每一处云影；本页未实现体积云投向地面的动态阴影。

沿街/海景/全景三个视角，OrbitControls 支持左键旋转、右键平移、滚轮缩放；展开天空控制可调整时间、云量、风和质量。显示街景复选框可对比纯天空。没有角色、语音或主应用服务；资源保持本地加载。

已检查资源就绪、旧天空移除、沿街白天、海景日落、夜晚路灯与星空，以及 WebGL 错误日志。独立天空基准不能代表这页完整街景的帧率。
