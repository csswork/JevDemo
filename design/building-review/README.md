# 近景建筑：材质统一与边缘质感

墙面、木材、屋瓦保留现有纹理和顶点配色，将照片底色归一并降低细节对比；控制法线、纹理 AO 和粗糙度范围。木材新增一次最低 mip 采样，与既有墙面/瓦面归一方法一致；无新增纹理文件或后处理。

Blender 在近景完整建筑和构件 LOD0 的木框、铝框、梁、檐板添加 4 mm 单段倒角，石质角线为 8 mm；宽度不超过最短边的 12%。封闭盒子才参与，不处理玻璃、植物和简化 LOD。顶点色、材质槽、UV、模型名称及材质批次数保留。

geometry-report.json 记录导出前后模型数据。三角形增加属于资产文件统计，构件会在场景中重复实例化，不能当作整帧新增三角形或 FPS 测试结果。未进行帧率基准测试。

实际浏览器检查：5678/sky-preview/ 的咖啡馆和花店，15:00 与 22:00。截图见本目录。构建与 lint 通过；未发现着色器编译错误。已有 Three.js 阴影类型和 render-target texture 克隆警告不在本次修改范围。

## 第二轮：接触阴影与玻璃层次

`streetContactShadows.ts` 在八栋精建建筑的窗洞内侧、台基与地面交界、护角、腰线和阳台下方绘制贴合接收面的环境遮蔽渐变。它是静态建筑接触遮蔽，不是动态物体的屏幕空间接触阴影。整批 428 个三角形，一次透明乘法绘制，零纹理；35–75 m 平滑淡出。深度测试和微小偏移限制阴影到实际表面，透明玻璃随后绘制。

`glassPaneUv.ts` 根据连通玻璃三角形归一窗坐标，修复精建模型米制 UV 被当作 0..1 使用的问题。仅合批时计算。街景真实室内玻璃增加低强度青蓝表面色、窗边层次和菲涅耳透光，采用既有单次玻璃绘制，无物理 transmission 额外场景渲染。室内映射窗补边缘遮蔽、室内墙角明暗；家具剪影不应用墙角遮蔽。

验证：两组不同大小、不同坐标窗面 UV 均独立得到 0..1；接触批次属性长度、有限坐标、地面高度及混合/深度设置检查通过。浏览器白天、斜角、22:00 检查无着色器编译错误；build、lint 通过。统计见 contact-report.json，未进行 FPS 基准测试。截图 contact-glass-day.png、contact-glass-oblique.png、contact-glass-night.png。
