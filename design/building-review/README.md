# 近景建筑：材质统一与边缘质感

墙面、木材、屋瓦保留现有纹理和顶点配色，将照片底色归一并降低细节对比；控制法线、纹理 AO 和粗糙度范围。木材新增一次最低 mip 采样，与既有墙面/瓦面归一方法一致；无新增纹理文件或后处理。

Blender 在近景完整建筑和构件 LOD0 的木框、铝框、梁、檐板添加 4 mm 单段倒角，石质角线为 8 mm；宽度不超过最短边的 12%。封闭盒子才参与，不处理玻璃、植物和简化 LOD。顶点色、材质槽、UV、模型名称及材质批次数保留。

geometry-report.json 记录导出前后模型数据。三角形增加属于资产文件统计，构件会在场景中重复实例化，不能当作整帧新增三角形或 FPS 测试结果。未进行帧率基准测试。

实际浏览器检查：5678/sky-preview/ 的咖啡馆和花店，15:00 与 22:00。截图见本目录。构建与 lint 通过；未发现着色器编译错误。已有 Three.js 阴影类型和 render-target texture 克隆警告不在本次修改范围。
