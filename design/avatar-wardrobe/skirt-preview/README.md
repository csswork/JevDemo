# 夏夏服装审核预览

地址：http://127.0.0.1:5678/design/avatar-wardrobe/skirt-preview/

仅设计目录使用；没有修改原 VRM、正式角色加载流程或场景。窄屏点击右上「服装控制」展开面板。

- 服装：新蕾丝裙、原服装对比、素体检查。
- 素体检查隐藏上衣、下装、鞋子和新裙；身体始终保留原材质与贴图，包括内衣、蕾丝和丝袜图案；仅切换服装网格的可见性。
- 站立、原地步态、转身、下蹲和保持蹲姿是预览用的程序姿态，不是正式动画包。
- 新裙由 Blender `create_lace.py` 创建；可编辑源文件 `lace-skirt.blend`，运行时资产 `skirt.glb`，原创程序绘制的花形刺绣、网眼和法线贴图。旧 `create_skirt.py`/`skirt.blend` 保留为首版记录，不再用于页面。
- 1040 个焊接布料节点，60 Hz 固定步长，8 次距离约束迭代。裙腰固定到 hips；软姿态弯曲参考防止大幅抬腿时布料翻到身体另一侧；其余节点用惯性、重力、微风、腿部/骨盆胶囊和地面碰撞求解。它是姿态驱动的 PBD 次级模拟，并非高精度有限元布料。
- 身体碰撞是近似体，不是逐三角形蒙皮碰撞；统计的“侵入”只针对这些胶囊。未实现布料自碰撞、手臂/开衫或椅子碰撞，不能将该数值当作所有穿模都已消除。
- 蕾丝使用 alpha-test + MSAA alpha-to-coverage，写入深度，避免 MToon 身体绘制顺序覆盖裙子。裙身有衬底，末端保留镂空，单面壳双面显示。

验证：独立 TypeScript 检查；`node --experimental-strip-types --test design/avatar-wardrobe/skirt-preview/cloth.test.mjs` 对实际 GLB 的网格运行 180 帧移动碰撞测试；浏览器人工复查站姿、走动及蹲姿侧面。单机窄屏观察约 60 FPS、CPU 动作＋求解约 4–5 ms/帧，不是 GPU 基准，也不代表全项目性能。

所有新增几何与程序贴图为本项目原创；夏夏源模型沿用项目原有许可。game-dev CLI 在本机 PATH 中不可用，本轮使用本地 Blender 导出与直接文件/运行时校验，没有生成技能 CLI 的 canonical package。
