# 天空渲染器：独立审阅原型

运行 `npm exec vite -- --config design/sky-preview/vite.config.mjs`，打开 `http://127.0.0.1:5678/design/sky-preview/index.html`。固定使用 5678，端口占用时直接报错。本目录的代码没有被街景、公园或主应用引用，也没有修改其现有天空、灯光、背景注册或用户偏好。

功能：24 小时时间滑杆、约 96 秒的一天播放、四个时间预设、云量百分比、月相、拖动环视、追随日月。切换时间预设保留当前云量；审阅无遮挡月亮时将云量设为 0%。

新增独立高层卷云：`setCirrusCoverage(amount)` 接收 0..1，积云仍由 `update` 的 coverage 参数控制。卷云先于积云合成，和日月共用昼夜颜色与风位移。两个预览页面都提供两个独立云量滑杆；查看无遮挡日月需要把两个云量都归零。工厂默认卷云量 0，预览页面主动设置 40%，既有单层云基准仍保持卷云关闭。

`skyRenderer.ts` 提供 `createSkyRenderer()`、`group`、`update(TimeState, dt, camera, coverage, phase)` 和 `dispose()`，只读取现有时间状态和天空调色表。背景天空、固定随机种子的三维星点、独立太阳/月亮圆盘、程序体积云分层绘制。太阳/月亮的显示物体不等于场景光源；后续主光的方向和颜色应读取同一时间状态。

时间采用项目现有北纬 34°、参考日期的简化太阳时计算。月轨为示意模型，月相着色可调，不承诺精确的真实月球天文位置。银河为程序示意纹理，不是真实星图。没有付费生成、下载素材或部署。

验证：独立 TypeScript 类型检查、oxlint、WebGL 着色器编译/浏览器错误日志、晴日/清晨/日落/星夜实际截图、月相控制和时间播放。截图是实际实时渲染，不是效果图。

尚未做街景/公园实场景基准测试。独立预览已加入低分辨率云层、质量分档和缓存噪声，GPU 测量结果见 `performance-report.md`。后续还需将天空输出接入场景的主光、雾和环境反射；公园原有 HDRI 包含可见背景，须检查双重天空问题。全部工作等待用户对预览方向的决定。

## 统一风场与性能修订

云量控制水平天气场的目标覆盖率，与云体密度分开。启动时对同一缓存噪声的天气 FBM 做 16,384 点采样并排序，以分位数映射覆盖率，避免噪声值集中使低云量也铺满天空；每帧只查表并更新一个阈值。0% 跳过云层，100% 为满覆盖，中间值平滑增减云区。百分比不是当前相机画面中云像素的精确占比：投影、沿视线叠加和局部天气位置会改变可见占比。浏览器已检查 0%、25%、50%、75%、100% 和切换时间保留云量，实际截图为 `coverage-fixed.png`。

方块轮廓修订：天气噪声改为穿过三个晶格轴的斜切面，CPU 分位数采样采用相同变换。天气场仅选择云区，边缘由三维密度等值面和细节侵蚀塑造，避免把二维覆盖轮廓直接挤成云柱。半分辨率云层存储预乘辐射和透明度，合成时做 3×3 加权平滑后还原直通颜色，再执行一次色调映射；这样降低抖动采样产生的边缘颗粒和放大锯齿，避免透明边缘黑圈。保留固定空间抖动以减少射线步进条带；没有加入帧历史，移动视角不会留下历史拖影。最新实际截图为 `cloud-edge-fixed.png`。

云的大形状、侵蚀细节、阴影密度全部读取同一个世界 XZ 平移量：每帧 `windOffset += windVelocity * dt`。风向为从 +X 向 +Z 的角度，风速单位为 m/s。改变风向或速度不会重置位移；风速 0 停止平移，时间滑杆只改变昼夜，不改变云的位置。日月保持独立绘制，云层随后覆盖它们。

均衡档默认将云层渲染到一半宽高的 RGBA16F 目标，32 步采样，再以全分辨率合成；天空、星点和日月保留全分辨率。节能档为 35% 宽高 / 20 步，精细档为 75% 宽高 / 48 步。无云时完全跳过云层目标与合成，白天跳过星点和银河噪声。光线无密度时跳过阴影密度，累积不透明后提前结束。64³ 的 R8 缓存噪声为 256 KiB，替代逐像素重复的程序哈希；没有下载额外纹理。缓存噪声周期化及过滤会改变部分云的细节，不承诺与旧版逐像素相同。

在 1280×720、DPR 1 时，均衡档云层目标约 1.76 MiB，精细档约 3.96 MiB，节能档约 0.86 MiB，另有 0.25 MiB 噪声缓存，不包含主画布、驱动分配或已有几何资源。目标仅在尺寸或质量改变时重分配，释放函数清理目标、纹理、几何和材质；页面退出取消动画。

`benchmark.html` 使用相同的视口、时间、云量和相机测试旧版与三个新质量档：每项预热 16 帧、采样 48 帧，冻结风和昼夜。旧版快照在 `baselineRenderer.ts`，实测原始结果在 `performance-results.json`。CPU 提交时间、RAF 帧间隔和 EXT_disjoint_timer_query_webgl2 的 GPU 计时分别记录；缺失的 GPU 计时绝不由 CPU 耗时替代。本次是在 Apple M2 Max 的桌面浏览器测量，测试时关闭其他本任务渲染标签。它不代表街景、公园完整场景或移动设备的帧率；正式接入前仍需联合场景验证。
