# 近景建筑差异化

本轮通过现有 Blender 生成脚本更新八栋近景建筑，使用项目自有几何与现有材质槽，不引入外部资产。

- 咖啡馆：浅暖墙面、淡色窗檐。
- 陶器店：深木构山墙与上层框架。
- 住宅：浅绿墙面、灰绿窗框、百叶板。
- 土产店：暖桃色墙面、灰绿窗框、四坡屋顶。
- 三层小楼：竖向门窗组合与中间立面线条。
- 居酒屋：深木构与暖色下层墙面。
- 花店：浅绿上层、淡色下层、百叶板与长窗。
- 木格住宅：木构框架与完整四坡屋顶。

颜色烘焙进顶点色。新增少量窗檐、木构和百叶几何，复用已有材质及合批流程，没有新增纹理、灯光、着色器或渲染通道。建筑位置、占地与门洞布局保持现有配置。窄建筑原先退化为双坡的四坡屋顶改为沿纵向的屋脊。
